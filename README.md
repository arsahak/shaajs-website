# Shaajs

Shaajs is an online store for beauty, fashion and lifestyle products in Bangladesh — built with Next.js, React, TypeScript, and Tailwind CSS.

- **Live site:** [www.shaajs.com](https://www.shaajs.com)
- **Stack:** Next.js (App Router, Turbopack), React, TypeScript, Tailwind CSS v4
- **Language:** English
- **Currency:** Bangladeshi Taka (৳)

## About

Shaajs — Beauty • Style • Lifestyle.
Customers can shop makeup, skincare, clothing, gadgets and more, with cash on delivery all over Bangladesh.

**Categories include:**

- Makeup
- Skincare
- Hair Care
- Fragrance
- Bath & Body
- Clothing
- Gadgets
- Jewelry, Bags & Footwear

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Environment

Create a `.env` file in the project root:

| Variable               | What it is                                                        |
| ---------------------- | ----------------------------------------------------------------- |
| `NEXT_PUBLIC_API_URL`  | Address of the backend API                                        |
| `NEXT_PUBLIC_SITE_URL` | Address of this site — `https://www.shaajs.com` in production     |
| `AUTH_SECRET`          | Secret used to sign login sessions                                |

## Scripts

- `npm run dev` — start the development server
- `npm run build` — build for production
- `npm run start` — run the production build
- `npm run lint` — run ESLint
